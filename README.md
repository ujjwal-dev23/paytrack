# PayTrack

A minimal, effortless payment and invoice tracking application.

## Overview
PayTrack is a full-stack monorepo designed to help users manage invoices, track financial health via a comprehensive dashboard, and send automated reminders to customers.

## Tech Stack
- **Frontend:** Preact, Vite, Tailwind CSS, Preact Signals
- **Backend:** Node.js (Express), Better-SQLite3
- **Monorepo Management:** pnpm Workspaces

## Quick Start
1. **Requirements:** Node.js v22.x and pnpm.
2. **Install Dependencies:**
   ```bash
   pnpm install
   ```
3. **Run Development Mode:**
   ```bash
   pnpm dev
   ```

## Structure
- `/frontend`: Preact application.
- `/backend`: Express.js API and SQLite database.
